# 零售促销实验业务数据

来源事件有来源编号、事件编号、修订、外部实体、发生时间和观察时间；同一来源同一事件的更高修订替代先前修订。主体映射只在来源与外部标识的组合内有效，无法映射的事件在现有摘要中列为未归属。通用金额是原始事件上的可选数值，不代表利润、节约额或结算结果。

报告发布接口保留报告正文和摘要哈希，相同编号不接受不同内容。业务口径、结论的适用范围和后续变化的影响需要与原始观察区分。

## 门店促销实验口径

实验分析 (`analytics/experiment.py`) 把计划分组、实际暴露、订单和退货连成一份可复核结果。

**计划分组** 由 `plan()` 按修订登记，修订带 `recorded_at`。任何带 `as_of` 的分析只采用该时点之前记录的修订，因此历史决定不会因为后来的分组纠正而改变其当时的计划；修订号必须递增，内容冲突或记录时间早于现有修订会被拒绝，避免用事后信息回填历史。`trial`/`control`/`none` 分别表示计划试验、计划对照和已撤出。

**实际暴露** 由分析窗口内发生、切观察时间不晚于 `as_of` 的 `touch` 或 `assignment` 事件决定。计划分组只说明当初打算怎么做，实际是否触达以事件为准。

由此每个门店落入以下一类：

| 分类 | 含义 |
| --- | --- |
| `trial` | 计划试验且窗口内已触达 |
| `control` | 计划对照且未被触达/入组 |
| `contaminated` | 计划对照但已触达或入组，不能代表反事实 |
| `unreached_trial` | 计划试验但窗口内未触达，不能代表受促销影响 |
| `withdrawn` | 计划中标记撤出 |
| `unplanned` | 不在计划内但发生了触达/入组 |

**销售口径**：`gross` 为订单金额合计，`return_amount` 为退货金额合计，`net = gross - return_amount`。订单与退货金额都必须非负；无法解析或非有限数值会报错，未映射主体按事件类型计入 `unmatched`。

**效应分层**：`effect.observed` 是不扣退货的计划组对照差（即容易高估的“活动期间销售额”）；`effect.after_returns` 换成净额；`effect.adjusted` 再只保留干净门店（`trial` 对 `control`）。`effect.reconciliation` 逐项拆出退货影响与暴露/污染影响，使高估来源可复核。

**不确定范围**：`effect.adjusted.interval` 先按门店间方差给出双侧 95% 区间。同一门店若同时出现在其他实验的 `trial`/`control` 中，则视为重叠活动：未提供 `attribution` 时区间扩到“零效应到全部观测差异”；提供 `attribution`（0–1）时按该比例保留未归因部分的范围；1 表示调用方声明完全归因，区间只反映抽样误差。

**决策留档**：`publish_analysis()` 把当时的分析结果（含 `as_of` 与 `attribution`）作为报告正文发布，摘要哈希固定，历史正文不再变化。`reconcile()` 用同一窗口与归因假设、但按当前全部已观察数据和最新计划重算，逐路径列出 `archived` 与 `current` 的差异；历史快照保持发布时的 `as_of`，因此不会看起来像基于后来才出现的数据。分店数量不足时区间为 `null` 并在 `notes` 中说明。
